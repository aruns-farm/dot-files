tmux cheat sheet

prefix Ctrl+t  ·  tmux 3.6a
~/.config/tmux/tmux.conf
Ctrl + t is the prefix. Press it, release, then the key. Everything marked ⌃t below needs it first. Keys without that marker work directly.

Sessions — from the shell

tmuxStart a new unnamed session
tmux new -s workNew session named work
tmux new -s work -c ~/dev…starting in a directory
tmux lsList all sessions
tmux aAttach to the most recent
tmux a -t workAttach to a named session
tmux kill-session -t workKill one session
tmux kill-serverKill everything — the fix when a config change seems ignored
Your t shortcut: t alone fzf-picks a session · t office attaches or creates it in the right directory · unknown names resolve through zoxide.
These are shell commands — run them from a normal terminal. Inside tmux, tmux new -s x fails with "sessions should be nested with care". See the next block for creating one from inside.

Sessions — from inside

⌃t: new -s apiCreate a new session and switch to it — the command prompt runs inside the server, so no nesting error
⌃t: new -s api -c ~/dev…starting in a directory
⌃tdDetach — leave it running (also closes the Claude popup)
⌃tsVisual session/window tree — pick and jump
⌃t$Rename this session
⌃t( )Previous / next session
⌃tDChoose a client to detach
⌃t:Command prompt — any tmux command
Prefer the shell? Create detached, then switch — this works from inside:
tmux new-session -d -s api -c ~/dev/api && tmux switch-client -t api

Panes (splits)

⌃t-Split horizontal — new pane below
⌃t\ / _Split full-width / full-height
⌃thjklMove left / down / up / right
⌃t←↓↑→Same, with arrows
⌃tHJKLResize by 5 (hold for repeat)

⌃t;Last pane (toggle back and forth)
⌃tqShow pane numbers — press one to jump
⌃txKill this pane (asks first)

⌃t!Break pane out into its own window

⌃tSpaceCycle to the next layout
⌃t⌥1…5Preset layouts (even-h, even-v, main-h, main-v, tiled)

Popups — the custom ones

⌃tglazygit in an 80% popup. Close with q.
⌃tyClaude Code in a popup — one persistent session per directory. Close with ⌃td.
⌃toOpen current directory in Finder
Two different exits: lazygit runs directly in the popup, so q quits it. Claude runs in a nested session, so you detach with ⌃td and the conversation keeps running.

Copy mode — scrolling & selecting

⌃t[Enter copy mode — now you can scroll
SpaceStart selection
EnterCopy selection and exit
vToggle rectangle (block) selection
/ / ?Search down / up
n / NNext / previous match
g / GTop / bottom of history
H / LTop / bottom of screen
qLeave copy mode
⌃t]Paste the buffer
⌃t=Choose from all paste buffers
Note: v is rectangle-toggle here, not begin-selection — this config uses tmux's vi defaults. Selection is Space, copy is Enter.

Saving & restoring

⌃tCtrlsSave all sessions now
⌃tCtrlrRestore saved sessions
Auto-save runs every 15 min. Auto-restore is off — it could fail partway at startup and drop you out of tmux entirely. Restore by hand after starting tmux. Saves live in ~/.local/share/tmux/resurrect/.
