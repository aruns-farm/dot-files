Node & Python — mise, not nvm

mise lsWhat's installed and what's active here
mise install node@22Add a version
mise use node@22Pin this project to a version
mise currentWhy am I on this version? — names the file that decided

fish uses mise; zsh still uses nvm and pyenv. They don't interfere. Your .nvmrc and .python-version files still work in fish — verified with node 20 and 22. Default outside a project is node 24. Global npm packages are per-version, so git cz exists on node 24 but not on a project pinned to 20 — same as nvm always behaved.

Gotchas

the things that will confuse you, and why
jjj…"Hold it Cowboy! 🤠" — discipline.cowboy() blocks hjkl+- after 10 rapid presses. It's a habit trainer. Use 10j. Delete lua/user/discipline.lua to disable.
Enter in normal modeRemapped. Terminals send Ctrl+m for Enter, and keymaps.lua maps Ctrlm → Ctrli, so Enter jumps forward in the jumplist instead of moving down a line.
s aloneNo longer substitutes a character — it waits for ss sv sh sf. Use cl to substitute. Flash.nvim was disabled to free this key.
; aloneWas repeat-last-f/t. Now a telescope prefix, and ;; is taken entirely. , still does reverse-repeat.
Mouse does nothingDeliberate. vim.opt.mouse = "" in options.lua. lazygit has mouseEvents: false too.
Ctrlt in fzftmux claims it as the prefix, so fzf's paste-file-path widget won't fire inside tmux.
tmux ignores a config changeA stale server is still holding the old config. tmux kill-server.
Spacer does nothingIt only rewrites hex colours, and only on the current line. No hex → silent no-op.
Spacei does nothingNeeds an attached LSP that provides inlay hints. Nothing renders in a CSS file or a plain buffer.
Wrong node versionHomebrew has its own node at /opt/homebrew/bin/node. If mise can't supply the version a project asks for, PATH falls through to it. Fix: mise install node@<version>.
zoxide warning on every shellPre-existing: zoxide init sits mid-file in ~/.zshrc and wants to be last. Harmless. fish doesn't have it.
:TSPlaygroundToggleWon't work — that plugin is archived. Use built-in :InspectTree and :Inspect.
